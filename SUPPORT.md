# 🆘 Support

1. Read the [README](./README.md).
2. Follow [development setup](./docs/development.md).
3. Check [troubleshooting](./docs/troubleshooting.md).
4. Search existing GitHub issues before opening a request.

For bugs, use the bug report form and include the affected page/API route, expected and actual behavior, versions, reproduction steps, and redacted output.

For security issues, follow [SECURITY.md](./SECURITY.md) and report privately. Never post database URLs, credentials, tokens, dumps, or private records publicly.
